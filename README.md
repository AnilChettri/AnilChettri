### 🧠 What I Do

> Most "AI portfolios" in 2026 are wrappers around an API call. I build the **boring, load-bearing parts** underneath — pipelines, auth flows, schemas, evaluation logic — the stuff that has to be right *before* an LLM feature can be trusted.

<div align="center">
<img src="https://readme-typing-svg.demolab.com?font=Fira+Code&size=15&pause=1800&color=8B5CF6&center=true&width=650&lines=schema+%E2%86%92+api+%E2%86%92+auth+%E2%86%92+ui;local-fallback+%2B+backend+%3D+resilient+by+default;automate+the+repetitive%2C+focus+on+the+hard+part" />
</div>

- 🏗️ Build **end-to-end systems** — schema → API → auth → UI, not just notebooks
- 🔐 Work at the intersection of **identity security** and **applied AI**
- 🧬 Design for **resilience by default** — hybrid fallback architectures, not single points of failure
- ⚙️ Automate the repetitive so I can spend cycles on the hard problems
